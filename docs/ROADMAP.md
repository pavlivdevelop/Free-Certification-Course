# Roadmap

## 2026-Q3
- Expand the free/conditional credential catalogue across technical disciplines.
- Add provider/source registry separate from credential rows.
- Add multilingual navigation and static catalogue entry point.
- Preserve a clean distinction between free learning, free badge, free certificate, and paid professional certification.

## 2026-Q4
- Add scheduled source checks for price/eligibility changes.
- Add country/region availability where issuers publish it.
- Add evidence fields for credential requirements and issuing/verification URL.
- Add community correction workflow and changelog.

## Future
- Import official catalogues where a provider exposes a machine-readable feed.
- Track credential retirement/replacement.
- Add automated duplicate detection.
- Add skill graph: credential → skills → roles → prerequisites → next credential.

# Status Labels

The catalog uses currency-neutral status labels so the same interface works globally.

| Label | Meaning |
|---|---|
| ✅ **Free** | The official source currently supports a no-cost path under normal access conditions. |
| ⚠️ **Conditional** | No mandatory payment in a qualifying case such as student/educator access, voucher, scholarship, campaign, partner access, or course-specific rules. |
| ⚪ **Unknown** | The current official evidence is insufficient to classify the price/access status. |
| ❌ **Paid / reference** | A paid credential/exam or a reference record kept outside the free core. |

**Important:** Free training does not automatically mean a free professional exam. A badge, completion certificate and professional certification are different credential types and must remain distinct.

No currency symbol is used for the global status model. Where an official provider publishes a specific price, the original currency may be recorded separately as source evidence.

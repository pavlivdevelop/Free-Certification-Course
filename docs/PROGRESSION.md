# Personal learning progression

The public site is local-first: progress lives in the browser and can be exported/imported as JSON. No account is required.

## Statuses

`Не начато` → `В процессе` → `Готово` or `Отложено`.

## XP and ranks

- In progress: 5 XP
- Completed: 100 XP
- Explorer: 0 XP
- Foundation: 150 XP
- Builder: 500 XP
- Engineer: 1200 XP
- Specialist: 2500 XP
- Expert: 5000 XP

## Recommendation model

The roadmap prefers free verified credentials first, then conditional opportunities, while moving from foundational to intermediate/associate and then professional/expert material. Category coverage is rewarded to avoid collecting dozens of near-duplicate badges.

## Future sync

The local tracker is intentionally privacy-preserving. A future optional account/sync layer can be added without changing the catalog schema.

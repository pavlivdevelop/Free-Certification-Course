# Catalogue scope

The repository now separates four layers:

1. **Free core** — credentials that are normally free on the issuer's current official page.
2. **Conditional free** — student/educator/voucher/scholarship/campaign/partner cases.
3. **Paid reference** — important professional certifications where the exam is paid; kept only so users can see the next career step.
4. **Source registry** — organisations and official portals worth monitoring for new credentials, across technical and non-technical domains.

The catalogue is deliberately broad: AI, software, data, cybersecurity, cloud, DevOps, networking, Linux, databases, QA, mobile, web, APIs, SRE, observability, data engineering, ML/LLM, quantum, mathematics, physics, electronics, embedded, RF, PCB, CAD/CAE, robotics, IoT, automation, telecom, satellite, GIS, manufacturing, energy, automotive, aerospace, biotech, healthcare, environment, business, finance, logistics, project management, and more.

A badge is not rewritten as a certification. A completion certificate is not presented as an exam credential. Where price or eligibility can change, the record is marked conditional and the official source remains authoritative.

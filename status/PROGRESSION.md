# Certification progression system

The roadmap is a skill tree, not a flat checklist.

## Levels

| Level | Typical target | XP per completed item |
|---|---|---:|
| Beginner | literacy, fundamentals, short labs | 10 |
| Foundation | core tool / language basics | 15 |
| Intermediate | multi-step practical work | 25 |
| Advanced | projects, architecture, specialized labs | 40 |
| Professional | industry role preparation | 60 |
| Expert | deep specialization / advanced validation | 100 |

## Recommended progression

**Explore → Beginner → Foundation → Intermediate → Advanced → Professional → Expert**

A user can choose a track such as AI Engineer, Python Developer, Cybersecurity, Cloud/DevOps, Networking, Embedded, Electronics/RF, Robotics, Mathematics/Physics or CAD/CAE. Prerequisites are advisory: the tracker should recommend missing fundamentals rather than block the user.

## Personal state

`site/progress.html` stores completion locally and supports:
- status changes;
- completion timestamps;
- XP and level calculation;
- search and category filters;
- JSON export/import.

No personal progress is written to the public catalogue.

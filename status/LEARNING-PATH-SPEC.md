# Learning Path Specification

OpenCertAtlas should recommend credentials as a progression, not as a flat list.

## Ordering model

1. `Explore` — orientation and literacy.
2. `Beginner` — first practical skill.
3. `Foundation` — core concepts and terminology.
4. `Intermediate` — independent implementation.
5. `Advanced` — multi-component technical work.
6. `Professional` — production-oriented capability.
7. `Expert` — specialized depth.
8. `Master` — long-form specialization and cross-domain mastery.

## Recommendation rules

A recommended next credential should prefer:

- unmet prerequisites over unrelated credentials;
- the user's selected domain;
- free credentials before conditional/paid references;
- stronger evidence confidence before weaker candidates;
- current/fresh sources before stale sources;
- diversity of skills rather than repeated credentials on the same topic.

## Safety rules

- Never claim that completing a course grants a professional certification unless the issuer says so.
- Never promote a credential-candidate to a free credential without evidence.
- Never treat HTTP availability as proof of current enrollment, price, or certification validity.
- Preserve issuer names, official credential names, product names, standards, and abbreviations verbatim.

## Portable state

User progress remains client-side by default. The public repository stores only the progression model and schema, never individual learner history.
